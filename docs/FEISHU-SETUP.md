# 飞书应用配置（Windows 版）

> 目标：让机器人在飞书里收发消息，并让日报卡片按钮可点击。
> 你需要一个能创建「企业自建应用」的飞书账号。应用属于哪个企业，就要用哪个企业的账号登录开放平台。

## 1. 创建应用

1. 打开 <https://open.feishu.cn/app>
2. 右上角确认企业/团队正确
3. 「创建企业自建应用」
4. 填写名称（如「杭电校园助手」）、图标、描述
5. 进入应用 → 「添加应用能力」→ **机器人** → 启用

## 2. 权限

在「权限管理」中至少开通：

- 接收消息（读取用户发给机器人的消息）
- 以应用身份发消息
- 以应用身份回复消息
- 消息卡片相关能力

不同租户的权限名称可能略有差异。保存后如果发消息返回权限错误，按错误提示补开权限并重新发布。

## 3. 事件订阅：收消息

「事件与回调」→「事件订阅」：

1. 订阅方式选 **长连接**
2. 添加事件：`im.message.receive_v1`
3. 保存

> 长连接不需要公网 IP、不需要 HTTPS 回调地址。机器人运行在 Windows 上主动连飞书。

## 4. 回调配置：卡片按钮

「事件与回调」→「回调配置」：

1. 添加回调
2. 选择 **卡片回传交互** / `card.action.trigger`
3. 订阅方式选 **长连接**
4. 保存

这一步是「刷新 / 本周课表 / 关闭日报」按钮可用的前提。
不配置时：日报卡片能收到，但点击按钮没有反调、没有 toast。

## 5. 发布版本

「版本管理与发布」→ 创建版本 → 申请发布。
自建应用通常需要企业管理员审核；审核通过后，机器人才对组织内用户可用。

**事件/回调配置修改后，也要重新发布版本。**

## 6. 把机器人加入会话

- 私聊：在飞书搜索应用名称，直接发消息
- 群聊：群设置 → 添加机器人 → 选择你的应用

第一次收到消息时，机器人会把该 `chat_id` 写入白名单（`%APPDATA%\hdu-campus\config\state.json` 的 `allowedChats`）。
之后只服务这个会话；换群需要手动调整白名单或清空后重新绑定。

## 7. 启动并测试

```cmd
start-bot.cmd
bot.cmd --check
bot.cmd --probe
bot.cmd --say "今天有课吗"
```

在飞书里发「你好」「今天有课吗」验证回复。

## 8. 开启日报

完成首次消息绑定后：

```cmd
bot.cmd --digest-on 8:00
```

会在每天 08:00 推送交互卡片。也可在飞书里发「开启日报」「日报 7:30」。

## 9. 常见问题

### 提示“该应用不存在”

当前登录开放平台的账号/企业不是创建 App 的那个。切换企业，或换创建 App 的账号。

### 机器人不回消息

按顺序检查：

1. `start-bot.cmd` 是否在运行
2. `bot.log` 是否显示 `正在连接飞书长连接…`
3. 事件订阅是否是长连接、是否订阅 `im.message.receive_v1`
4. 应用是否已发布
5. 机器人是否在该会话中
6. `state.json` 的 `allowedChats` 是否包含当前 `chat_id`

### 按钮没反应

在「回调配置」中添加 `card.action.trigger`（卡片回传交互），选长连接，**发布新版本**，然后：

```cmd
stop-bot.cmd
start-bot.vbs
```

点击后运行 `bot.cmd --runs 5`，应出现 `"source":"card"`。

### 需要重新选择应用/企业

- 退出飞书开放平台，重新登录正确企业
- 重新创建应用后，运行 `setup.cmd` 更新 App ID / Secret
- 注意：新应用的 `chat_id` 可能不同，必要时清空 `allowedChats` 后重新绑定
